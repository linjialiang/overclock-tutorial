# 超频原理 · 章节导读

这一部分讲"为什么"和"怎么判断"，不绑定某一台机器。九个章节可以按顺序读，也可以按问题跳读。

| 章节 | 讲什么 | 什么时候读 |
|---|---|---|
| [01 频率与倍频](/principles/01-frequency) | 频率从哪来、Turbo 与全核、倍频和外频的区别 | 想知道"超频到底改的是哪个数" |
| [02 电压与供电](/principles/02-voltage) | VCCIN / VID / Vcore、四种电压模式、LLC、功耗与温度 | 想弄懂电压、掉压和模式选择 |
| [03 内存与 XMP](/principles/03-memory) | SPD / JEDEC / XMP、时序、IMC、四条为什么难 | 想开 XMP 或手动超内存 |
| [04 缓存与 Ring](/principles/04-cache) | Ring 的作用、缓存倍频、缓存不稳怎么测 | 核心稳了，想继续压延迟 |
| [05 集成显卡](/principles/05-igpu) | iGPU 的倍频、电压、带宽瓶颈与取舍 | 想超核显，或在核显/独显间取舍 |
| [06 主板与芯片组](/principles/06-motherboard) | 哪些主板能超什么、H81/B85/H97/Z97 的差别 | 选主板或判断手里的板子能不能超 |
| [07 电源与散热](/principles/07-power-cooling) | 12V、功率估算、散热器、风道与正压 | 超频前判断电源和散热够不够 |
| [08 稳定性验证](/principles/08-stability) | 负载类型、测试时长、WHEA、核心与缓存不稳的区别 | 想知道"怎样才算稳" |
| [09 调参与体质](/principles/09-tuning) | 体质、电压-频率-温度三角、参数联动、手动 vs Tuner | 想从推荐值收敛到自己的设置 |
| [术语表](/principles/glossary) | 常用术语速查 | 读到不认识的词 |

## 推荐阅读路径

- **完全新手**：01 → 02 → 03 → 08，先建立频率、电压、内存、稳定性四块。
- **只想开 XMP**：03 → 06，重点看 IMC、QVL 和四条内存的难度。
- **只想超 CPU**：01 → 02 → 08 → 09。
- **核心稳了想继续**：04 → 08，缓存要单独验证。
- **遇到蓝屏/报错**：08 → 02，先分清核心不稳还是缓存/内存不稳。
