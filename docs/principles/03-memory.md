# 内存与 XMP

内存超频和 CPU 超频不是同一套逻辑：CPU 看的是倍频和电压，内存看的是"参数表 + 平台能不能接住"。一条内存能标称 2400，不代表插在你的板子上、配你的 CPU、四条一起插也能跑 2400。

## SPD、JEDEC 与 XMP 是什么关系

![图 1：内存条上的 SPD 芯片同时存着 JEDEC 默认档和厂商预验证的 XMP 档，开 XMP 就是应用后者；DDR3-2400 的实际时钟只有 1200 MHz，监控软件显示的是这个值](/principles/03-spd-xmp.svg)

- **SPD**：内存条上的一颗小芯片，记录这条内存的参数表。
- **JEDEC**：内存行业的默认标准档。DDR3 常见默认是 1333 / 1600 MHz `[官方页]`。
- **XMP**（Intel Extreme Memory Profile）：Intel 定义的扩展档，把厂商验证过的高频参数（频率、时序、电压）写进 SPD，让主板"一键读取" `[官方页]`。

所以"开 XMP"不是主板随意加频，而是**主板把内存条自带的一组厂商预验证参数应用上**。它仍然属于内存超频：Intel 明确把 XMP 归为 memory overclocking，并提示可能影响处理器保修 `[Intel]`。这组参数是否在你的 CPU + 主板上稳定，是另一回事。

| 项目 | 示例值 | 怎么读 |
|---|---|---|
| 频率 | DDR3-2400 | 等效 2400 MT/s，实际时钟 1200 MHz |
| 时序 | 11-13-13-30 | CL-tRCD-tRP-tRAS，数字越小越快 |
| 电压 | 1.65 V | 这组参数需要的 DRAM 电压 |
| Command Rate | 2T | 四条常用 2T，两条可试 1T |

监控软件里内存频率显示为 1200 MHz，是因为它显示的是**实际时钟**，不是等效频率——DDR 是双倍数据率，1200 × 2 = 2400 MT/s，不是"只跑了一半"。表中的 1.65 V 属 DDR3 时代 XMP 示例；DDR3 时代的 XMP 与后来的 XMP 2.0（DDR4）、XMP 3.0（DDR5）不是同一代规范，参数不要跨代照搬。

> AMD 平台要按代际区分：AM5 + DDR5 对应的是 EXPO；DDR3/DDR4 老平台常见的是主板厂商实现的 DOCP、A-XMP、OCP 等，名字和 XMP 不同，不能一概写成 EXPO。

## 四个关键参数

![图 2：一次读取依次经过 tRCD、CL 到数据输出，tRP 是预充电时间，tRAS 覆盖 ACT 到预充电的最短间隔；下方的 1T / 2T 是命令间隔，不是频率](/principles/03-timings.svg)

| 参数 | 含义 | 影响 |
|---|---|---|
| 频率 | 等效传输频率，如 DDR3-2400 | 带宽上限 |
| 时序 | CL-tRCD-tRP-tRAS | 延迟；同频下越小越快 |
| Command Rate | 1T / 2T | 1T 快但更难稳；四条常用 2T 排错 `[经验]` |
| DRAM 电压 | 内存条供电 | 高频/低时序的余量；越高越热 |

频率和 Command Rate 最容易让人误判：前者看的是等效频率，而不是软件显示的时钟；后者 2T 只是排错手段，不是"四条必须 2T"的硬规定 `[经验]`。

## 谁能决定"这条内存能不能跑"

一条内存能不能跑到标称频率，取决于四层，缺一层都可能失败：

1. **内存条本身**：颗粒、PCB、散热、XMP 档位。
2. **CPU 的 IMC**（内存控制器）：决定能推多高、能带几条。
3. **主板**：走线、DIMM 插槽数量、QVL（内存兼容列表）。
4. **BIOS 训练**：开机时内存控制器会做一次参数训练，失败就回到默认或不开机。

**IMC** 决定了两个上限：能推多高的频率、能带几条内存。内存条再好，IMC 带不动就是带不动——这也是"同一套内存换 CPU 就不稳"的原因。**QVL** 的价值在于"别人在这块板子上试过"，尤其是高频四条；选主板时怎么看待 QVL，见[主板与芯片组](/principles/06-motherboard)。

## 为什么四条比两条难

![图 3：两根内存时每通道只挂一条；四根时每通道挂两条，信号负载翻倍、IMC 训练余量更小，通常要更多电压或更松时序，结果是更难稳而不是更快](/principles/03-four-dimm.svg)

- 每条通道挂两个 DIMM，负载翻倍，信号完整性变差。
- Rank 交错更复杂，IMC 训练余量更小。
- 同频率下，四条通常需要更多电压或更松的时序；"四条 2400"比"两条 2400"更容易出内存错误 `[经验]`。
- 所以"两条能上更高频率、四条只能降一档"是正常的物理限制，不是主板有毛病 `[经验]`。四条插满时，把目标定得保守一点，比反复试边界更划算。

## 两个容易被混淆的电压

| 电压 | 加在哪 | 作用 |
|---|---|---|
| DRAM Voltage | 内存条 | 颗粒工作电压，影响频率/时序余量 |
| VCCSA / VCCIO | CPU 内部 IMC 侧 | 内存控制器与 IO 的电压，影响高频内存训练 |

DRAM 电压不是"越高越好"，VCCSA/VCCIO 也不是"超内存必加"。以 Haswell 这类 Intel 平台为例，这两项分别对应内存颗粒和 CPU 内部的系统代理/IO；新平台的 rail 名称和位置会变，先确认手册再动。先 Auto 记录，出问题再单独动一项。

判断方法很简单：**加 DRAM 电压解决的是"颗粒跑不动"，加 VCCSA/VCCIO 解决的是"IMC 带不动"**。两者混着加，最后既不知道问题在哪，也不安全。CPU 侧的电压分层见[电压与供电](/principles/02-voltage)。

## 内存训练与开机失败

内存不是"设了频率就直接跑"。开机时内存控制器会做一次训练（Training）：尝试不同的时序/电压组合，找到能工作的参数；具体算法由平台和 BIOS 决定。

- 训练失败的表现：反复重启、黑屏、蓝屏、自动回到默认频率。
- 训练失败不等于内存坏了，更多是"这组参数在这套平台上余量不够"。
- 四条内存的训练难度明显高于两条，因为每条通道的负载更重。
- 开机阶段直接蓝屏，通常就是初始化/训练阶段就已经失败，而不是进系统之后才算错。

处理方法：回退一档电压或频率，确认能稳定开机后，再逐步逼近边界。最忌讳"再加一点电压硬顶"。

## 收益、代价与判定

- **收益**：带宽提升对核显、压缩、渲染、部分游戏有帮助；延迟下降对游戏帧数有帮助。
- **代价**：温度、稳定性余量、IMC 压力。
- **判定**：软件里显示 `2400` 只证明参数已应用，**不等于稳定**。稳定要看内存测试零错误 + 冷启动 + 真实应用。

## 测试怎么选

| 测试 | 主要压什么 | 适合 |
|---|---|---|
| 系统内存测试（如 AIDA64 Stress system memory） | 内存控制器 + 内存条 | 快速筛查 |
| 独立内存测试工具 | 内存条本身，压力更高 | 边界验证 |
| 真实应用（压缩、渲染、游戏） | 综合 | 最终确认 |

任何单一测试都只覆盖它自己的负载。"过 1 小时"只能说明这一小时没问题，不能说明永久稳定。实用顺序是：先快速筛查，再用压力更高的工具验边界，最后跑真实应用并做一次冷启动。

具体怎么用这几款工具，见[烤机工具](/tools/)：Windows 内筛查用 [TestMem5](/tools/testmem5)，需要排除操作系统影响时用 [MemTest86+](/tools/memtest86plus) 从 U 盘启动。

## 频率与时序的取舍

- 频率高、时序松：带宽高，延迟一般。
- 频率低、时序紧：延迟低，带宽一般。
- 两者都想要：需要更高电压或更好颗粒，余量更小。

日常使用，频率到平台甜点、时序按 XMP 即可；极限压时序属于"跑分玩法"，稳定成本高。

## XMP 之外的手动超频

XMP 是厂商替你调好的一组参数；手动超频是在 XMP 基础上继续压：

1. 先让 XMP 稳定。
2. 再尝试提高频率或收紧时序，每次只改一项。
3. 每次改完做内存测试 + 冷启动。
4. 出现错误先回退，不要靠加电压硬顶。

对已经接近平台上限的四条高频内存，继续压的收益很小、风险却不低，优先保证稳定。内存超频的性价比通常不如"把 CPU 稳住"，因为收益集中在带宽敏感的场景，而代价是整机随时可能开不了机。
