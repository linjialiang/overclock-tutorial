# 主板与芯片组

超频不是 CPU 一个人的事：同样一颗解锁倍频的 CPU，插在不同主板上能做的事情完全不一样。芯片组决定"有没有这个选项"，主板做工决定"这个选项能用到多高"。本章按芯片组分档讲清楚谁能超、谁不能超，再给出不看电路图也能判断供电的办法。

## 芯片组分级逻辑

两家平台的命名逻辑是一致的：按定位分档，只有高端档解锁 CPU 超频。

| 厂商 | 入门 | 主流 | 高端/解锁 |
|---|---|---|---|
| Intel | H | B | Z（解锁超频） |
| AMD | A | B | X |

- **Intel**：H（入门/主流）、B（商用/主流）、Z（解锁超频）。主流桌面只有 Z 系列解锁 CPU 倍频，HEDT 的 X 系列也开放；内存超频支持则因芯片组而异。
- **AMD**：不能只看字母。B650/B650E 及以上同时解锁 CPU 与内存；B840 只解锁内存；A620/A620A 只解锁内存，PRO 600/665 两者都不解锁。具体以 AMD 官方芯片组表为准 `[官方页]`。

有一条容易被忽略的界线：**主板解锁的是"倍频"，不是"电压"**。能不能改电压、能改多少，还取决于 BIOS 实现。所以"Z 系列"只保证选项里有倍频，不保证每一项电压都能手动指定。

## Haswell 时代：四款芯片组的能力对比

LGA1150 这一代最能说明"芯片组决定上限"这件事，四款芯片组的能力差异非常清晰：

| 芯片组 | 内存超频/XMP | CPU 倍频 | 核显倍频 | 每通道 DIMM | 定位与优缺点 |
|---|---|---|---|---|---|
| H81 | **否** `[Intel]` | 否 | 否 | 1 | 最入门；便宜、接口少，只能跑默认内存 |
| B85 | **否** `[Intel]` | 否 | 否 | 2 | 商用/主流；接口更全，仍不能超 |
| H97 | **是** `[Intel]` | 否 | 否 | 2 | 可开 XMP 跑高频内存，但不能超 CPU 倍频 |
| Z97 | **是** `[Intel]` | **是** | **是** | 2 | 全解锁；支持多卡、供电更好，价格更高 |

> 内存超频与每通道 DIMM 数来自 Intel ARK；CPU/核显倍频是否可选还取决于具体主板的 BIOS，表中按常见情况标注，不能替代主板手册。

**结论**：想要 CPU 倍频超频，必须 Z97（或 Z87）；只想开 XMP，H97 就够；H81/B85 在芯片组层面不支持内存超频（ARK 写 No），但个别主板仍提供 XMP 选项并限速在 DDR3-1600，不能把"芯片组不支持"写成"所有主板都没有 XMP" `[Intel]`。

### H81

- 优点：便宜，适合办公/家用。
- 缺点：每通道 1 条 DIMM（最多 2 条内存）、芯片组层面不支持内存超频、接口少 `[Intel]`；个别主板可开 XMP，但会被限速在 DDR3-1600。
- 适合：不超频、预算优先。

注意 DIMM 数量那一栏：每通道只有 1 条，意味着插满也只有两条内存，容量和带宽上限都被锁死了。

### B85

- 优点：比 H81 多 SATA/USB，支持 4 条内存，商用稳定。
- 缺点：芯片组层面不支持内存超频，也不支持 CPU 超频 `[Intel]`；XMP 是否出现在 BIOS 取决于主板，且会被限速。
- 适合：办公、商用、不折腾。

B85 和 H81 的区别主要在"接口够不够用"，而不是"能不能超"——两者都不能超 CPU 倍频；内存 XMP 也要看主板，且会被限速。

### H97

- 优点：支持内存超频（可开 XMP 跑高频内存），接口齐全，价格适中 `[Intel]`。
- 缺点：多数 H97 主板不提供 CPU 倍频与核显倍频选项，具体以主板手册为准。
- 适合：想用高频内存、但不超 CPU 的用户。

H97 是这一代里最容易被误解的一档：它能开 XMP，于是很多人以为它也能超 CPU。不能——XMP 是内存条自带的超频档，不是 CPU 倍频。

### Z97

- 优点：CPU/内存/核显全解锁，支持多显卡，供电和 BIOS 功能最全 `[Intel]`。
- 缺点：价格高；供电一般的 Z97 也不适合大幅超频。
- 适合：K 系列 CPU + 超频用户。

**一句话**：能不能超 CPU，看芯片组是不是 Z；能不能开 XMP，看芯片组是否支持内存超频；两者都想要，只能选 Z。

## 现代平台概览

换代之后，档位逻辑没变，只是名字和数字变了：

| 平台 | 内存超频 | CPU 超频 | 备注 |
|---|---|---|---|
| Intel H610 | **否** `[Intel]` | 否 | 入门，适合不超频 |
| Intel B660 / B760 | **是** `[Intel]` | 否 | 主流，可开 XMP |
| Intel H770 | **是** `[Intel]` | 否 | 中高端，接口更全 |
| Intel Z690 / Z790 | **是** `[Intel]` | **是** `[Intel]` | 全解锁，适合超频 |
| AMD A620 / A620A | 是（PRO 600/665 否）`[官方页]` | 否 | 入门；只解锁内存 |
| AMD B650 / B650E | 是 `[官方页]` | 是 `[官方页]` | 主流超频 |
| AMD X670 / X870 | 是 `[官方页]` | 是 `[官方页]` | 高端，通道更多 |
| AMD B840 | 是 `[官方页]` | **否** `[官方页]` | 只解锁内存，不能超 CPU |

> 现代芯片组的具体差异以 Intel ARK / AMD 官方芯片组页面为准；上表只做档位概览。

两点值得记住：Intel 这边，"能不能开 XMP"下放到了 B 系列，不再像 H81/B85 那样一刀切；AMD 这边从 B650 级别起同时解锁 CPU 和内存，但 B840 只解锁内存，A620 也只解锁内存，不能按字母一概而论。

## 供电、散热与 BIOS 功能

芯片组给了"能不能超"的许可，主板做工决定"能超多高"。看四个地方：

- **相数不等于能力**：看每相电流、DrMOS、VRM 散热片，而不是只看"几相"。
- **VRM 散热**：超频时 VRM 温度可能比 CPU 还高，散热片和风道很重要。
- **BIOS 功能**：LLC 档位、Offset 支持、Profile 保存、内存时序项是否完整。
- **QVL**：四条高频内存尤其要看主板的内存兼容列表。

BIOS 选项不完整是最隐蔽的限制：有些板子的核心电压只有 Auto 和固定值，没有 Offset，就没法在保留空闲降压的前提下调压——原理上的取舍见 [电压与供电](/principles/02-voltage)。

## 供电的简单判断

不需要看电路图，也能判断一块板子适不适合超频；下面几条是经验判断，不是硬指标 `[经验]`：

| 观察点 | 好的信号 | 风险信号 |
|---|---|---|
| VRM 散热片 | 独立散热片、覆盖完整 | 裸奔或很小 |
| 供电接口 | 8 pin CPU 供电 | 只有 4 pin |
| 官方定位 | Z/X 系列、超频宣传 | H/B 入门定位 |
| BIOS | LLC/Offset/Profile 齐全 | 选项残缺 |
| 内存 QVL | 高频四条有验证 | 列表很短 |

相数不是唯一标准，但"供电接口 + 散热片 + BIOS 功能"三项都弱的板子，不适合大幅超频。

顺带一个联动项：供电能力最终会体现在 [电源与散热](/principles/07-power-cooling) 这套前置条件里——VRM 供电不足的板子，换再大的电源也补不回来。

## 同样的 Z97，为什么差别很大

芯片组只决定"能不能超"，不决定"能超多高"。同样是 Z97（以下为经验观察） `[经验]`：

- 供电相数多、每相电流大、VRM 有散热片的板子，能承受更高电流。
- BIOS 选项完整的板子，更容易精细调电压。
- 内存走线好的板子，四条高频更容易稳。
- 便宜的 Z97 可能只有 4+1 相、没有 VRM 散热，推到高倍频就吃力。

所以"Z97"只是入场券：先确认解锁项，再看供电和 BIOS；同芯片组主板实际能跑到的频率也可能差一档电压。

## 本章要点

- 芯片组决定"能不能超"：Intel 主流桌面 H/B 不解锁 CPU 倍频，Z 才解锁（HEDT 的 X 也解锁）；AMD 不能只看字母，B650 级别起解锁 CPU，B840/A620 只解锁内存。
- 主板解锁的是倍频，不是电压；能不能改电压、改多少，取决于 BIOS 实现。
- Haswell 时代：H81/B85 在芯片组层面不支持内存超频，H97 能开 XMP，只有 Z97 能超 CPU 与核显倍频 `[Intel]`；个别 H81/B85 主板可开 XMP，但会被限速。
- 判断供电不看相数，看 VRM 散热片、CPU 供电接口（8 pin 优于 4 pin）、BIOS 选项完整度和内存 QVL。
- 同是 Z97 差别也可以很大：芯片组只是入场券，供电与 BIOS 才决定能超到多高。
