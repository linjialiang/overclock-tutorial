# 主板与芯片组

超频不是 CPU 一个人的事：同样一颗解锁倍频的 CPU，插在不同主板上能做的事情完全不一样。芯片组决定"有没有这个选项"，主板做工决定"这个选项能用到多高"。

## 芯片组分级逻辑

两家平台的命名逻辑是一致的：按定位分档，只有高端档解锁 CPU 超频。

| 厂商 | 入门 | 主流 | 高端/解锁 |
|---|---|---|---|
| Intel | H | B | Z（解锁超频） |
| AMD | A | B | X |

- **Intel**：主流桌面只有 Z 系列解锁 CPU 倍频，HEDT 的 X 系列也开放；内存超频支持则因芯片组而异 `[Intel]`。
- **AMD**：不能只看字母。B650/B650E 及以上同时解锁 CPU 与内存；B840 只解锁内存；A620/A620A 只解锁内存，PRO 600/665 两者都不解锁。具体以 AMD 官方芯片组表为准 `[官方页]`。
- 有一条容易被忽略的界线：**主板解锁的是"倍频"，不是"电压"**。能不能改电压、能改多少，还取决于 BIOS 实现。

## Haswell 时代：四款芯片组的能力对比

![图 1：H81、B85、H97、Z97 的内存 XMP、CPU 倍频、核显倍频与每通道 DIMM 能力矩阵](/principles/06-haswell-chipsets.svg)

- **H81**：最入门，便宜、接口少；每通道 1 条 DIMM，插满也只有两条内存 `[Intel]`。
- **B85**：比 H81 多 SATA/USB，可插 4 条，但同样不能超 CPU 倍频，芯片组层面也不支持内存超频 `[Intel]`。
- **H97**：能开 XMP 跑高频内存，但多数主板不提供 CPU 与核显倍频选项——这一档最容易被误解：XMP 是内存条自带的超频档，不是 CPU 倍频。
- **Z97**：CPU/内存/核显全解锁，支持多卡，供电和 BIOS 功能最全；供电一般的 Z97 也不适合大幅超频 `[Intel]`。

> 内存超频与每通道 DIMM 数来自 Intel ARK；CPU/核显倍频是否可选还取决于具体主板的 BIOS，图中按常见情况标注，不能替代主板手册。

**结论**：想要 CPU 倍频超频，必须 Z97（或 Z87）；只想开 XMP，H97 就够；H81/B85 在芯片组层面不支持内存超频（ARK 写 No），但个别主板仍提供 XMP 选项并限速在 DDR3-1600，不能把"芯片组不支持"写成"所有主板都没有 XMP" `[Intel]`。

换代之后，档位逻辑没变，只是名字和数字变了：

- AMD 这边从 B650 级别起同时解锁 CPU 和内存，B840 只解锁内存，A620 也只解锁内存，不能按字母一概而论 `[官方页]`。

## 供电、散热与 BIOS 功能

![图 3：VRM 散热片、CPU 供电接口、BIOS 选项与内存 QVL 四个观察点，以及各自的"好信号"与"风险信号"](/principles/06-vrm-check.svg)

上面四条是经验判断，不是硬指标 `[经验]`。芯片组给了"能不能超"的许可，主板做工决定"能超多高"。

BIOS 选项不完整是最隐蔽的限制：有些板子的核心电压只有 Auto 和固定值，没有 Offset，就没法在保留空闲降压的前提下调压——原理上的取舍见[电压与供电](/principles/02-voltage)。

## 同样的 Z97，为什么差别很大

芯片组只决定"能不能超"，不决定"能超多高"。同样是 Z97，供电相数与每相电流、VRM 散热片、BIOS 选项完整度、内存走线都会让实际能跑到的频率差出一档电压，便宜的 Z97 推到高倍频就吃力 `[经验]`。所以"Z97"只是入场券：先确认解锁项，再看供电和 BIOS。

顺带一个联动项：供电能力最终会体现在[电源与散热](/principles/07-power-cooling)这套前置条件里——VRM 供电不足的板子，换再大的电源也补不回来。

## 本章要点

- 芯片组决定"能不能超"：Intel 主流桌面 H/B 不解锁 CPU 倍频，Z 才解锁（HEDT 的 X 也解锁）；AMD 不能只看字母，B650 级别起解锁 CPU，B840/A620 只解锁内存。
- 主板解锁的是倍频，不是电压；能不能改电压、改多少，取决于 BIOS 实现。
- Haswell 时代：H81/B85 在芯片组层面不支持内存超频，H97 能开 XMP，只有 Z97 能超 CPU 与核显倍频 `[Intel]`；个别 H81/B85 主板可开 XMP，但会被限速。
- 判断供电不看相数，看 VRM 散热片、CPU 供电接口（8 pin 优于 4 pin）、BIOS 选项完整度和内存 QVL。
- 同是 Z97 差别也可以很大：芯片组只是入场券，供电与 BIOS 才决定能超到多高。
