# 调参与体质

前面几章讲的是"每个参数是什么"，本章讲"怎么把它们调成一台机器自己的值"。同一个型号的两颗 CPU，达到同一频率所需的电压并不相同，这就是体质；而调参的目标不是追最高频率，是在电压、频率、温度之间找到这台机器能长期站住的点。本章给出一套可复用的收敛流程，并说明手动调参与依赖主板自动超频各自的适用场景。

## 三种常见思路

| 思路 | 做法 | 适合谁 | 代价 |
|---|---|---|---|
| 频率优先 | 先定目标频率，再把电压加到稳定 | 追求性能 | 温度/功耗高 |
| 电压优先（降压） | 固定频率，把电压压到最低稳定值 | 日常静音/低温 | 验证时间更长 |
| 折中 | 找"温度可接受"的频率上限 | 大多数日常用户 | 需要反复试 |

三条路没有对错，只有取舍：

- **频率优先**把电压当工具，稳定即可，不追求低电压；代价是温度和功耗都往上走。
- **电压优先**反过来，频率固定，把电压一点点往下压；每次降压都要重新验证，所以慢。
- **折中**先确定一个温度舒服的频率，再在这个频率上尝试降压。

新手建议从"折中"开始：先有一个能用的频率，再谈优化。一上来就压最低电压，很容易在反复失败中失去参照。

## 体质只影响"所需电压"

体质好 = 同频所需电压低、同频更凉；不代表"耐压更高"或"能跑更高温度"。温度控制线对谁都一样。

这句话拆开看：

- 体质决定的是**达到某个频率需要多少电压**，仅此一项。
- 体质好不等于能承受更高电压，也不等于更高温度下还能稳。
- Tjmax 一类的保护点是统一的设计值，不会因为体质好就放宽。
- 所以"大雕"的优势是可以跑得更低更凉，而不是可以更放肆。

**判断标准**：同频所需电压低 = 好，同频需要更高电压 = 差。

## 电压、频率、温度的三角

三者是一个三角：固定两个，第三个就会被约束。

- 固定频率和电压 → 温度由散热决定。
- 固定频率和温度 → 电压上限由散热决定。
- 固定电压和温度 → 频率上限由体质决定。

所以"为什么不能又高频率、又低电压、又低温"——因为这三个目标互相冲突，只能选两个。

调参时最常见的误判就来自这里：以为"再加一点电压就能上去"，但如果散热已经到顶，加电压换来的只是更高温度，频率反而会因为节流掉下来。

## 一个参数联动的例子

假设目标频率往上提 100 MHz：

1. 只改倍频，其他不动。
2. 跑短时筛查。如果掉频/报错，说明电压不够。
3. 加 0.01 V，再测；重复到稳定。
4. 稳定后记录：频率、BIOS 目标、实测 Vcore、温度、功耗。
5. 如果电压还没到位、温度先到线，说明散热是瓶颈，应降频而不是继续加电压。

这就是"一次只改一项"的实际含义：让每一次变化都能归因。同时改倍频和电压，稳定了也不知道是哪一项起作用；失败了更不知道该退哪一个。

第 5 步是最容易被忽略的：**温度先到线，说明这条路已经走到头**，继续加电压只会更热。此时正确动作是降频，或者先解决[电源与散热](/principles/07-power-cooling)问题。

## 怎么从推荐值收敛到自己的值

1. 先用"市面常见"的中间值起步。
2. 跑短时筛查，稳定后每次降 0.01 V，直到出现错误或降频。
3. 回加 0.01~0.02 V 作为余量。
4. 换散热、换室温、换 BIOS 后重新验证。

推荐值只是起点，最终值一定是你这台机器实测出来的。

几个执行细节：

- 从"中间值"起步，而不是从区间的下限起步。下限是别人机器的边界，你的机器很可能还没到。
- 往下压的时候每次 0.01 V，不要一次压 0.05 V。步长太大，你只能知道"这一步不行"，不知道该退多少。
- 找到边界后必须回加一点余量。边界值本身没有余量，室温升高几度就可能翻车。
- 收敛出来的值要配合[稳定性验证](/principles/08-stability)才算数，单次通过不作结论。

## 手动，还是跟随 Tuner

主板通常提供一个"自动超频"入口（不同厂商叫法不同，例如 OC Tuner），它会自动调整 CPU 甚至内存的频率与电压 `[手册]`。它和手动设置是两种完全不同的做法。

| | 手动 | 跟随 Tuner |
|---|---|---|
| 控制力 | 高，电压/缓存都可控 | 低，由主板决定 |
| 上手 | 需要理解 VID/Vcore | 一键，适合先跑起来 |
| 风险 | 设错电压 | 可能自动加压偏高、改动内存参数 |
| 适合 | 想降压、大雕、可复现 | 不想折腾、先验证平台 |

### 按体质和需求选

| 体质/需求 | 更适合 | 原因 |
|---|---|---|
| 普通体质、刚入门 | 跟随 Tuner | 自动规则给保守电压，先跑起来 |
| 大雕（同频电压低） | 手动 | Tuner 偏向"给够"，会浪费低温/低压优势 |
| 雷（同频需要更高电压） | 手动 | 自动规则不一定够，需要自己找稳定点 |
| 想写教程/可复现 | 手动 | 每一步可控、可记录 |
| 只想确认平台能超 | Tuner | 快速验证，再决定是否细化 |

手动方法内部还有一层选择：先用手动固定电压把目标频率验证下来，稳定后再换成负偏移（Offset）之类的模式，把空闲时的降压保留下来。固定电压适合"只验证某个电压稳不稳"，因为它排除了变量；日常使用则更适合保留动态降压。具体模式差别见[电压与供电](/principles/02-voltage)。

### 为什么 Tuner 不会识别你的体质

- Tuner 依据的是**主板的保守规则**，不是你这颗 CPU 的实际特性。
- 同一型号的不同样品，达到同一频率所需电压不同；Tuner 没有手段知道你是哪一种。
- 所以"别人用 Tuner 跑出来的倍频和电压"不能照抄，自己跑出来的结果也不能直接当结论。
- Tuner 可能顺手改动内存参数或基准时钟，跑完要复核内存频率、电压和 Cache 设置是否还是你要的。
- 它的定位是"先让平台跑起来"的起点，不是可以长期使用的日常配置。

一句话：Tuner 给的是"大概率能用"的值，手动调出来的是"这台机器最好"的值。前者省事，后者省电、省温度。

## 本章要点

- 三种思路（频率优先、电压优先、折中）只是取舍不同；新手从"折中"起步最稳。
- 体质只影响同频所需电压，不影响耐压上限和温度控制线。
- 电压、频率、温度是三角关系，固定两个，第三个必然被约束。
- 收敛流程：中间值起步 → 每次降 0.01 V 找边界 → 回加 0.01~0.02 V 余量 → 环境变化后重验。
- 手动适合大雕、雷、想可复现的场景；Tuner 适合先跑起来，但它按保守规则给值，不会识别样品体质。
