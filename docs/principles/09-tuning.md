# 调参与体质

前面几章讲的是"每个参数是什么"，本章讲"怎么把它们调成一台机器自己的值"。同一个型号的两颗 CPU，达到同一频率所需的电压并不相同，这就是体质；调参的目标不是追最高频率，而是在电压、频率、温度之间找到这台机器能长期站住的点。

## 三种常见思路

| 思路 | 做法 | 适合谁 | 代价 |
|---|---|---|---|
| 频率优先 | 先定目标频率，再把电压加到稳定 | 追求性能 | 温度/功耗高 |
| 电压优先（降压） | 固定频率，把电压压到最低稳定值 | 日常静音/低温 | 验证时间更长 |
| 折中 | 找"温度可接受"的频率上限 | 大多数日常用户 | 需要反复试 |

三条路没有对错，新手建议从"折中"开始：先有一个能用的频率，再谈优化。一上来就压最低电压，容易在反复失败中失去参照。

## 体质主要影响"所需电压"

- 体质主要决定的是**达到某个频率需要多少电压**，并由此影响同频功耗与温度。
- 体质好不等于能承受更高电压，也不等于更高温度下还能稳。
- Tjmax 一类的保护点在同一个 SKU 上是固定设计值，不会因为体质好就放宽；不同平台/型号并不相同 `[Intel]`。

判断标准：同频所需电压低 = 好，同频需要更高电压 = 差。

## 三角：固定两个，第三个被约束

![图 1：电压、频率、温度构成三角，固定频率与电压则温度由散热决定，固定频率与温度则电压上限由散热决定，固定电压与温度则频率上限由体质决定；体质只决定同频所需电压，不改变耐压上限与该 SKU 的 Tjmax](/principles/09-triangle.svg)

所以"又高频率、又低电压、又低温"做不到，只能选两个。

调参时最常见的误判就来自这里：以为"再加一点电压就能上去"。散热已经到顶时，加电压换来的只是更高温度，频率反而会因为节流掉下来。

## 收敛流程

![图 2：六步收敛——中间值起步、短时筛查、每次降 0.01 V 复测、报错或掉频即边界、回加 0.01~0.02 V 留余量、换环境后复验；右侧对比手动与 Tuner，下方列出 Intel 与 AMD 的调参入口](/principles/09-converge.svg)

推荐值只是起点，最终值一定是这台机器实测出来的：

- 从"中间值"起步，不要从区间下限起步——下限是别人机器的边界，你的机器很可能还没到。
- 每次降 0.01 V，不要一次压 0.05 V `[经验]`；步长太大，只能知道"这一步不行"，不知道该退多少。
- 找到边界后必须回加 0.01~0.02 V 余量 `[经验]`；边界值本身没有余量，室温升几度就可能翻车。
- 收敛出来的值要配合[稳定性验证](/principles/08-stability)才算数，单次通过不作结论。

一个联动的例子：目标频率 +100 MHz 时只改倍频，短测掉频或报错说明电压不够，加 0.01 V 再测；如果电压还没到位、温度先到线，说明散热是瓶颈，应降频而不是继续加电压。

## 手动，还是跟随 Tuner

主板通常提供一个"自动超频"入口（不同厂商叫法不同，例如 OC Tuner），会自动调整 CPU 甚至内存的频率与电压 `[手册]`。它和手动设置是两种完全不同的做法。

- **手动**：电压、缓存都可控，适合降压、大雕、雷，以及需要可复现的场景。
- **Tuner**：按主板的保守规则给值，不会识别你这颗样品的体质 `[经验]`；可能顺手改动内存参数或基准时钟，跑完要复核。
- Tuner 的定位是"先让平台跑起来"的起点，不是可以长期使用的日常配置。

| 体质/需求 | 更适合 | 原因 |
|---|---|---|
| 普通体质、刚入门 | 跟随 Tuner | 自动规则给保守电压，先跑起来 |
| 大雕（同频电压低） | 手动 | Tuner 偏向"给够"，会浪费低温/低压优势 |
| 雷（同频需要更高电压） | 手动 | 自动规则不一定够，需要自己找稳定点 |
| 想写教程/可复现 | 手动 | 每一步可控、可记录 |
| 只想确认平台能超 | Tuner | 快速验证，再决定是否细化 |

手动内部还有一层选择：先用手动固定电压把目标频率验证下来，稳定后再换成负偏移（Offset）之类的模式，把空闲时的降压保留下来；模式差别见[电压与供电](/principles/02-voltage)。

## 不同平台的调参入口

本文主线是 Intel 传统的"核心倍频 + Cache 倍频 + 三套电压"模型。换到新平台，名字和入口会变，但"先定频率、再配电压、最后验证"的顺序不变。

| 平台 | 常见入口 | 注意 |
|---|---|---|
| Intel 传统桌面（Haswell 等） | CPU Core Ratio、Cache Ratio、Vcore / Cache / Graphics Voltage | 本文主线；模式数量看主板 |
| Intel 12 代及以后（混合架构） | P-core / E-core 分频、每核倍频、AVX Offset、Cache Ratio `[Intel]` | P/E 核角色不同；AVX Offset 只在 AVX 负载时降倍频 |
| AMD Ryzen | PBO、Curve Optimizer、EXPO `[官方页]` | PBO/CO 支持型号有限，不等于手动倍频；以主板/CPU 支持为准 |

- **Intel 混合架构**：P-core 与 E-core 各有倍频，也可以逐核设置 `[Intel]`；两者共享封装功耗和散热，拉高一组会挤占另一组的余量；稳定性要分别覆盖 P 核与 E 核负载。
- **AVX Offset** 只在 AVX 负载时降倍频，用来换温度/电压余量，不是"所有负载都降" `[Intel]`。
- **AMD PBO** 用主板供电余量自动提高加速频率和持续时间，效果取决于 CPU 体质、主板供电和散热 `[官方页]`。
- **Curve Optimizer** 调的是 AVFS 电压-频率曲线（每核或全核），支持型号有限，以 Ryzen Master 和主板说明为准 `[官方页]`；Auto Offset 只是压力测试推导出的起点，应用后仍要用自己的负载复验。
- **EXPO** 只负责内存档，和 PBO/CO 是两件事。
