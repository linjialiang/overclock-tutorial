# 集成显卡

集成显卡（iGPU）是 CPU 封装里除了核心和缓存之外的第三个可超频对象。它的倍频、电压都是独立项，看起来像"白送的性能"，实际上和核心抢同一份功耗、同一份散热、同一份内存带宽。

## iGPU 与核心共享什么

![图 1：CPU 封装内的核心、iGPU、Ring 与内存控制器，以及三者共享的封装功耗、散热与内存带宽](/principles/05-igpu-shared.svg)

- iGPU 不是独立芯片，就在 CPU 封装里面，**共享封装功耗上限和散热**。
- 它与核心共享 Ring 和内存控制器（互连细节见[缓存与 Ring](/principles/04-cache)），核显吃的内存带宽也是从系统内存里分的。
- 所以核显超频不是"免费的"：它会和 CPU 抢功耗、抢温度、抢带宽。

## 倍频与 50 MHz 步进

核显倍频（`CPU Graphics Ratio`）和核心倍频是**两套独立设置**，改核显倍频不会改变核心频率，反之亦然。

以某些 Haswell SKU 的 HD 4600 为例，默认最高 1.25 GHz；同一款 HD 4600 在不同 SKU 上也有 1.15 GHz 等版本 `[Intel]`。核显倍频以 **0.5x（50 MHz）** 为步进 `[Intel]`：

| 倍频 | 等效频率 |
|---|---|
| 25x | 1250 MHz |
| 26x | 1300 MHz |
| 27x | 1350 MHz |
| 28x | 1400 MHz |
| 30x | 1500 MHz |

实际数值以 BIOS 显示为准；不同主板对核显倍频的档位命名（Ratio 或 Frequency）不完全一致。步进只有 50 MHz，意味着每一步都很细、收益也偏小——这正是核显超频"收益有限"的原因之一。

## 核显电压

- `CPU Graphics Voltage` 是核显专用电压，和核心电压分开。
- 有些 BIOS 在核显电压下也提供 Adaptive / Additional Turbo 这类模式，名字和核心电压的选项相同，但作用对象完全不同；改错页面会得到"我明明调了核心电压却没变化"的错觉。
- **核显电压不是必加项**：先只提倍频、电压保持 Auto，是标准起手式。

## 内存带宽是主要瓶颈

![图 2：单通道约为双通道一半的相对带宽，以及四条 DIMM 不增加通道数、XMP 优先的取舍](/principles/05-igpu-bandwidth.svg)

核显没有独立显存，用的是系统内存，所以它的性能天花板往往不是核显自己，而是内存带宽：

- **双通道是底线**，单通道会直接砍半带宽；内存频率越高，核显收益越明显。
- 四条内存不会增加双通道平台的通道数，理论带宽不变；最多靠 rank 交错带来小幅收益，但会给 IMC 更大压力。
- 所以给核显超频之前，先把内存开好 XMP，往往比拉核显倍频更划算。内存部分的原理见[内存与 XMP](/principles/03-memory)。

## 收益与风险

- **收益取决于应用**：轻度 3D、视频解码、老游戏有感知；大型游戏仍受限于核显规模，超 50 MHz 不会改变结论 `[经验]`。
- **风险**：花屏、驱动崩溃、游戏闪退。出现这些现象通常先降一档或回 Auto，而不是马上加电压。
- **与 CPU 超频的取舍**：CPU 已经接近温度墙时，不建议再拉核显——抢来的功耗和散热会直接削弱核心的稳定性。

## 与独显的取舍

| 场景 | 建议 | 原因 |
|---|---|---|
| 有独显 | 核显通常只负责视频输出/解码，超频收益很小 | 优先把功耗留给 CPU |
| 无独显 | 核显是唯一图形输出，超频有意义 | 但要接受它和 CPU 抢功耗 |
| 小机箱/闷罐 | 谨慎，甚至不超 | 核显超频会明显推高整机温度 |

判断标准很简单：核显超频的收益必须和"核心少了一点温度余量"相比。有独显时这笔交易几乎总是亏的；没有独显时才有讨论空间。

## 核显超频怎么验证

1. 先只提倍频，电压保持 Auto，跑 15~20 分钟 GPU 负载 `[经验]`。
2. 稳定后再开实际 3D 应用/游戏，观察花屏、驱动崩溃、闪退。
3. 出问题先降一档；确认电压不足且温度允许，再小步加电压。
4. 核显稳定不代表 CPU 稳定，反之亦然，必须分开验证。

最后一条最容易被忽略：核显和核心共享封装，核显负载会把 CPU 温度推高，所以核显测试"过"了，核心的超频结论可能反而被削弱。完整的分开验证方法见[稳定性验证](/principles/08-stability)。

核显能不能超，还要看主板允不允许——这就要说到芯片组。下一章：[主板与芯片组](/principles/06-motherboard)。
