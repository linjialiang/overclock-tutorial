# 集成显卡

集成显卡（iGPU）是 CPU 封装里除了核心和缓存之外的第三个可超频对象。它的倍频、电压都是独立项，看起来像"白送的性能"，实际上和核心抢同一份功耗、同一份散热、同一份内存带宽。本章讲清核显超频能拿到什么、代价是什么，以及怎么验证。

## iGPU 与核心共享什么

核显不是一个独立芯片，它就在 CPU 封装里面：

- iGPU 与 CPU 核心在同一个封装里，**共享封装功耗上限和散热**。
- iGPU 与核心共享 Ring 和内存控制器，核显吃内存带宽。
- 所以 iGPU 超频不是"免费的"：它会和 CPU 抢功耗、抢温度、抢带宽。

| 共享的东西 | 对超频的含义 |
|---|---|
| 封装功耗上限 | 核显负载会挤占核心的功耗预算 |
| 散热 | 核显发热会让 CPU 温度一起上升 |
| Ring 与内存控制器 | 核显和核心走同一条互连，参考 [缓存与 Ring](/principles/04-cache) |
| 系统内存 | 核显没有独立显存，带宽全靠内存 |

## 倍频与 50 MHz 步进

核显倍频（CPU Graphics Ratio）和核心倍频是**两套独立设置**，互不等同——改核显倍频不会改变核心频率，反之亦然。

以 Haswell 的 HD 4600 为例，默认最高 1.25 GHz `[Intel]`。核显倍频以 **0.5x（50 MHz）** 为步进：

| 倍频 | 等效频率 |
|---|---|
| 25x | 1250 MHz |
| 26x | 1300 MHz |
| 27x | 1350 MHz |
| 28x | 1400 MHz |
| 30x | 1500 MHz |

实际数值以 BIOS 显示为准；不同主板对核显倍频的档位命名（Ratio 或 Frequency）不完全一致。步进只有 50 MHz，意味着每一次提升都很细，收益也是线性偏小的——这正是核显超频"收益有限"的原因之一。

## 核显电压

核显有自己的专用电压项，通常叫 `CPU Graphics Voltage`：

| 项目 | 说明 |
|---|---|
| CPU Graphics Voltage | 核显专用电压，和核心电压分开 |
| 共享功耗 | 核显电压/频率升高，封装总功耗升高 |
| 共享散热 | 核显负载会让 CPU 温度一起上升 |

两点提醒：

1. **不要和核心电压混**。有些 BIOS 在核显电压下也提供 Adaptive / Additional Turbo 这类模式，名字与核心电压的选项相同，但作用对象完全不同，改错页面会得到"我明明调了核心电压却没变化"的错觉。
2. **核显电压不是必加项**。先只提倍频、电压保持 Auto，是核显超频的标准起手式。

## 内存带宽是主要瓶颈

核显没有独立显存，用的是系统内存。因此核显的性能天花板往往不是核显自己，而是内存带宽：

- **双通道是底线**，单通道会直接砍半带宽。
- 内存频率越高，核显收益越明显。
- 四条内存对核显带宽有帮助，但对 IMC 稳定性压力更大。

换句话说，给核显超频之前，先把内存开好 XMP 往往比拉核显倍频更划算。内存部分的原理见 [内存与 XMP](/principles/03-memory)。

## 收益与风险

- **收益取决于应用**：轻度 3D、视频解码、老游戏有感知；大型游戏仍受限于核显规模，超 50 MHz 不会改变结论。
- **风险**：花屏、驱动崩溃、游戏闪退。出现这些现象通常先降一档或回 Auto，而不是马上加电压。
- **与 CPU 超频的取舍**：CPU 已经接近温度墙时，不建议再拉核显——抢来的功耗和散热会直接削弱核心的稳定性。

## 与独显的取舍

| 场景 | 建议 | 原因 |
|---|---|---|
| 有独显 | 核显通常只负责视频输出/解码，超频收益很小 | 优先把功耗留给 CPU |
| 无独显 | 核显是唯一图形输出，超频有意义 | 但要接受它和 CPU 抢功耗 |
| 小机箱/闷罐 | 谨慎，甚至不超 | 核显超频会明显推高整机温度 |

判断标准很简单：核显超频的收益必须和"核心少了一点温度余量"相比。有独显时这笔交易几乎总是亏的；没有独显时才有讨论空间。

## 核显超频怎么验证

1. 先只提倍频，电压保持 Auto，跑 15~20 分钟 GPU 负载。
2. 稳定后再开实际 3D 应用/游戏，观察花屏、驱动崩溃、闪退。
3. 出问题先降一档；确认电压不足且温度允许，再小步加电压。
4. 核显稳定不代表 CPU 稳定，反之亦然，必须分开验证。

最后一条最容易被忽略：核显和核心共享封装，核显负载会把 CPU 温度推高，所以核显测试"过"了，核心的超频结论可能反而被削弱。完整的分开验证方法见 [稳定性验证](/principles/08-stability)。

核显能不能超，还要看主板允不允许——这就要说到芯片组。下一章：[主板与芯片组](/principles/06-motherboard)。

## 本章要点

- iGPU 与核心同封装，共享功耗上限、散热、Ring 和内存带宽，所以核显超频不是免费收益。
- 核显倍频以 0.5x（50 MHz）为步进，与核心倍频是两套独立设置；Haswell 的 HD 4600 默认最高 1.25 GHz `[Intel]`。
- 核显电压是独立项（`CPU Graphics Voltage`），与核心电压无关，起手应保持 Auto。
- 核显的真实瓶颈是内存带宽：双通道是底线，内存频率比核显倍频更值得先调。
- 有独显时不建议超核显；验证必须与 CPU 分开做，且要留意核显负载抬高核心温度。
