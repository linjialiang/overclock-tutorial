# 频率与倍频

超频最直观的动作就是"把频率调高"，但频率不是一个可以随便填的数字，它由基准时钟和倍频相乘得到，而倍频又受 CPU 型号和芯片组限制。这一章讲清楚频率是怎么算出来的、官方睿频和自己设的倍频差在哪、以及为什么"改倍频"和"改 BCLK"是两条风险完全不同的路。

## 频率从哪里来

CPU 频率 = **基准时钟（BCLK）× 倍频**。绝大多数平台 BCLK 是 100 MHz，所以 47x 就是 4700 MHz。

| 概念 | 含义 | 注意 |
|---|---|---|
| BCLK | 基准时钟 | 改动它会影响 CPU、内存、PCIe，现代平台一般不动 |
| 倍频 | 核心倍频 | 超频最常用的旋钮 |
| Turbo | 官方自动加速 | 按活跃核心数给不同上限 |
| 全核同频 | 所有核心锁同一倍频 | 比单核 Turbo 更难，电压需求更高 |

**关键**：Turbo 是官方行为，倍频超频是用户行为。以一款官方基础频率 4.00 GHz、最大睿频 4.40 GHz 的 K 系列型号为例 `[Intel]`，设 47x = 4700 MHz 已经超出官方 Turbo 范围，属于超频。

### 基础频率、睿频与全核睿频

这三个词经常被混用，其实说的是三件事：

- **基础频率**：官方规格页标称的默认工作频率，也是功耗等级（TDP）的参考点。它不代表"只能跑这么高"，而是"默认状态下的标称值"。
- **睿频（Turbo）**：负载和温度允许时，CPU 自己往上加速。它是自动的，用户不参与决策。
- **全核睿频**：所有核心同时活跃时能到的上限，通常低于单核能到的最高睿频。
- **全核同频**：用户把所有核心锁在同一个倍频上——这是超频，不是官方行为，也是"全核 47x"这类说法的来源。

区别的实际意义很简单：官方最大睿频是**少核**的上限，不代表全核能跑到；而全核同频要求每个核心都稳，电压需求自然更高。

### Turbo bin：官方那张"几核几倍频"的表

Turbo bin 指的是 CPU 内部那张"活跃核心数 → 可用倍频"的对应表。少核活跃时能摸到最高睿频档，核心越多，档位越低（具体分档以厂商规格和数据表为准 `[Intel]`）。

这张表由厂商在出厂时写死，用户改不了。它带来两个结论：

1. 官方最大睿频只是"最好的情况下"的上限，全核满载时到不了。
2. 用户设定的全核倍频一旦超过官方最大睿频档，就已经是超频——不管 BIOS 里那个数字看起来多普通。

## 两条路径：改倍频，还是改 BCLK

既然频率 = BCLK × 倍频，理论上两个乘数都能动。但它们的副作用完全不同。

### 倍频路径

- 只影响 CPU 核心频率（前提是 BCLK 保持 100 MHz）。
- 变量单一，出问题容易归因，是日常超频的标准做法。
- 需要 CPU 和芯片组都支持，详见下一节。

### BCLK 路径

- BCLK 是整台机器的基准时钟：CPU、内存、PCIe 频率都从它派生。
- 抬高 BCLK，会连带把内存频率和 PCIe 频率一起抬高，所以往往不是 CPU 先不稳，而是内存或 PCIe 设备先出问题。
- 现代平台一般不动 BCLK：分频机制虽然能隔离一部分影响，但边界很难摸，收益也不如直接改倍频。

### 两条路径的差别

| | 改倍频 | 改 BCLK |
|---|---|---|
| 影响范围 | 主要只有 CPU 核心 | CPU、内存、PCIe 一起变 |
| 前置条件 | CPU 解锁倍频 + 芯片组支持 | 平台允许调整，且能接受连带影响 |
| 主要风险 | 电压/温度不够，好定位 | 内存或 PCIe 先崩，难归因 |
| 适合场景 | 日常超频、目标明确 | 极限超频、特定平台的细调 |

一句话：**改倍频是"只动一个齿轮"，改 BCLK 是"动整条传动轴"**。新手没有理由先碰 BCLK。

## K 系列与解锁

不是所有 CPU 都能改倍频，这是硬性限制：

- Intel 桌面平台常见的是带 **K** 后缀的型号解锁倍频（此外还有 X、KF、KS 等解锁型号）`[Intel]`。
- 非解锁型号即使主板是 Z 系列，也不能改核心倍频。
- 芯片组这一侧也要解锁：Intel 平台通常只有 Z 级别开放 CPU 倍频（AMD 的规则不同），具体分档见[主板与芯片组](/principles/06-motherboard)。

另外要分清两件事：**主板解锁的是"倍频"，不是"电压"**。能不能改电压、能改多少，还取决于 BIOS 实现。内存超频（XMP）的解锁又是另一套条件，和 CPU 倍频是否解锁无关，见[内存与 XMP](/principles/03-memory)。

## 改倍频会牵动什么

超频不是"把某一项拉满"，而是在几道墙之间找平衡。改倍频只是这条链的起点：

**频率 ↑ → 需要更高电压 → 功耗上升 → 温度上升 → 散热与供电承压**

| 你改的 | 直接变化 | 连带影响 | 先看什么 |
|---|---|---|---|
| 倍频 ↑ | 频率 ↑ | 需要更高电压；功耗约按 V²×f 上升；温度 ↑ | 频率有没有掉 |
| 核心电压 ↑ | 稳定性余量 ↑ | 功耗按电压平方上升；温度 ↑ | 温度与 Vcore |

这张表是普适的：所有平台都是"频率 → 电压 → 功耗 → 温度 → 散热/供电"这条链。所以调倍频的顺序应该是：

1. 先只改倍频，其他都不动，跑一轮短时负载。
2. 看有效频率有没有掉——掉了就是撞上了某道墙（功耗、温度或电流）。
3. 频率确实到位但不稳，才考虑加电压；加电压之前先确认温度还有余量。
4. 电压怎么加、加在哪一层，见[电压与供电](/principles/02-voltage)。

反过来也成立：如果电压已经加上去、温度却先到线，那瓶颈是散热，继续加电压只会更热，正确的做法是降频。

> 记住一个原则：一次只改一项。这样每一次"稳"或"不稳"都能归因到具体参数，否则你只是在碰运气。

## 本章要点

- CPU 频率 = BCLK × 倍频；BCLK 通常是 100 MHz，所以 47x = 4700 MHz。
- 官方睿频按活跃核心数分档（Turbo bin），最大睿频是少核上限；把全核锁到超过这个档位就是超频。
- Intel 桌面平台常见的是 K 后缀（以及 X、KF、KS 等）解锁倍频，且通常需要 Z 级别芯片组配合；主板解锁的是倍频，不是电压。
- 改倍频会沿"频率 → 电压 → 功耗 → 温度 → 供电/散热"整条链传导，所以一次只改一项。
- BCLK 同时驱动 CPU、内存和 PCIe，动它会牵连全局；日常超频走倍频这条路。
