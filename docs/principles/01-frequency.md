# 频率与倍频

超频最直观的动作就是"把频率调高"，但频率不是一个可以随便填的数字：它由基准时钟和倍频相乘得到，而倍频又受 CPU 型号和芯片组限制。这一章讲清楚频率是怎么算出来的、官方睿频和自己设的倍频差在哪、以及为什么"改倍频"和"改 BCLK"是两条风险完全不同的路。

## 频率从哪里来

![图 1：频率 = BCLK × 倍频，100 MHz 配 47x 就是 4700 MHz；基础频率、最大睿频、全核睿频是官方三档，用户把全核锁到超过最大睿频档就已经是超频](/principles/01-frequency-formula.svg)

CPU 频率 = **基准时钟（BCLK）× 倍频**。绝大多数平台 BCLK 是 100 MHz，所以 47x 就是 4700 MHz。

| 概念 | 含义 | 注意 |
|---|---|---|
| BCLK | 基准时钟 | 改动它会影响 CPU、内存、PCIe，现代平台一般不动 |
| 倍频 | 核心倍频 | 超频最常用的旋钮 |
| Turbo | 官方自动加速 | 按活跃核心数给不同上限 |
| 全核同频 | 所有核心锁同一倍频 | 比单核 Turbo 更难，电压需求更高 |

- **基础频率**：官方规格页的标称值，也是 TDP 的参考点；它不代表"只能跑这么高"。
- **睿频（Turbo）**：负载和温度允许时 CPU 自己加速，用户不参与决策。
- **全核睿频**：所有核心同时活跃时的上限，通常低于单核最高睿频。
- **全核同频**：用户把所有核心锁在同一倍频——这是超频，不是官方行为。

以一款官方基础频率 4.00 GHz、最大睿频 4.40 GHz 的 K 系列型号为例 `[Intel]`，设 47x = 4700 MHz 已经超出官方 Turbo 范围。区别的实际意义很简单：官方最大睿频是**少核**的上限，全核同频要求每个核心都稳，电压需求自然更高。

### Turbo 分档：官方那张"几核几倍频"的表

Turbo bin 是社区叫法，Intel 文档里对应的是 Turbo Ratio Limits：一张"活跃核心数 → 可用倍频"的默认对应表。少核活跃时能摸到最高睿频档，核心越多，档位越低（具体分档以厂商规格和数据表为准 `[Intel]`）。

默认表由厂商在出厂时写入；带 K 的解锁型号配合 Z 系主板，可以在 BIOS 里用 `Per Core` 逐档覆盖不同活跃核心数的倍频上限 `[手册]`。但它覆盖的是"上限"，不改变默认表本身，也换不来稳定性：

1. 官方最大睿频只是"最好的情况下"的上限，全核满载时到不了。
2. 用户设定的全核倍频一旦超过官方最大睿频档，就已经是超频——不管 BIOS 里那个数字看起来多普通。
3. 逐档覆盖之后，仍要按全核负载重新验证稳定性；改得上去不等于稳得住。

## 两条路径：改倍频，还是改 BCLK

![图 2：改倍频只影响 CPU 核心，内存与 PCIe 不变；改 BCLK 会让 CPU、内存、PCIe 一起变，往往内存或 PCIe 先出问题，也更难归因](/principles/01-ratio-vs-bclk.svg)

- **倍频路径**：BCLK 保持 100 MHz 时只影响 CPU 核心，变量单一，出问题容易归因，是日常超频的标准做法。
- **BCLK 路径**：在 Haswell 这类平台上，BCLK 是整台机器的基准时钟，CPU、内存、PCIe 频率都从它派生。抬高 BCLK 会连带抬高内存和 PCIe 频率，所以往往不是 CPU 先不稳，而是内存或 PCIe 设备先出问题。
- 现代平台一般不动 BCLK：分频机制虽能隔离一部分影响，部分平台也已改用独立时钟，但边界很难摸，收益也不如直接改倍频。

| | 改倍频 | 改 BCLK |
|---|---|---|
| 影响范围 | 主要只有 CPU 核心 | CPU、内存、PCIe 一起变 |
| 前置条件 | CPU 解锁倍频 + 芯片组支持 | 平台允许调整，且能接受连带影响 |
| 主要风险 | 电压/温度不够，好定位 | 内存或 PCIe 先崩，难归因 |
| 适合场景 | 日常超频、目标明确 | 极限超频、特定平台的细调 |

一句话：**改倍频是"只动一个齿轮"，改 BCLK 是"动整条传动轴"**。新手没有理由先碰 BCLK。

## K 系列与解锁

不是所有 CPU 都能改倍频，这是硬性限制：

- Intel 桌面平台常见的是带 **K** 后缀的型号解锁倍频；KF、KS 与 X 系列也属于解锁型号，具体以该型号 ARK 页面的 Unlocked 字段为准 `[Intel]`。
- 非解锁型号不能改核心倍频，即使主板是 Z 系列；部分世代可用 BCLK 绕过，但风险高，也不属于倍频超频。
- 芯片组这一侧也要解锁：Intel 主流桌面通常只有 Z 级别开放 CPU 倍频（HEDT 的 X 系列也开放；AMD 的规则不同），具体分档见[主板与芯片组](/principles/06-motherboard)。

另外，主板解锁的是**倍频**，不是电压；能改多少电压取决于 BIOS。内存 XMP 又是另一套条件，见[内存与 XMP](/principles/03-memory)。

## 改倍频会牵动什么

改倍频只是这条链的起点：

**频率 ↑ → 需要更高电压 → 功耗上升 → 温度上升 → 散热与供电承压**

| 你改的 | 直接变化 | 连带影响 | 先看什么 |
|---|---|---|---|
| 倍频 ↑ | 频率 ↑ | 需要更高电压；功耗约按 V²×f 上升；温度 ↑ | 频率有没有掉 |
| 核心电压 ↑ | 稳定性余量 ↑ | 功耗按电压平方上升；温度 ↑ | 温度与 Vcore |

这张表是普适的：所有平台都是"频率 → 电压 → 功耗 → 温度 → 散热/供电"这条链。所以调倍频的顺序应该是：

1. 先只改倍频，其他都不动，跑一轮短时负载。
2. 看有效频率有没有掉——掉了就是撞上了某道墙（功耗、温度或电流）。
3. 频率确实到位但不稳，才考虑加电压；加电压之前先确认温度还有余量。
4. 电压怎么加、加在哪一层，见[电压与供电](/principles/02-voltage)。

反过来也成立：如果电压已经加上去、温度却先到线，那瓶颈是散热，继续加电压只会更热，正确的做法是降频。
