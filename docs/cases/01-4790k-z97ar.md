# 案例 01：i7-4790K + Z97-AR（32 GB DDR3-2400）

> 超友：匿名投稿
> 目标：47x 日常，尽量压低核心电压
> 结论：47x 稳定；Adaptive 下 1.20 / 1.24 没有改变实际电压，实测仍在 1.26 V；内存 1.55 V 是下限。

## 2. 目标

- CPU：47x 全核（4700 MHz），日常使用。
- 电压：从默认 VID 往下降，目标 1.20–1.24 V。
- 内存：XMP DDR3-2400，四条 32 GB 稳定。
- 缓存：先保持默认 40x，核心稳定后再考虑提高。

## 5. 关键发现

### 5.1 1.20 和 1.24 没有改变实际电压

两组的 VID 都是 1.262 V、Vcore 都是 1.264 V，频率、温度、功耗也在同一水平。标称 1.20 V 那轮功耗反而高约 4 W，属于背景负载波动，不是电压效果。

原因：这颗 4790K 在 47x 的原生 VID 就是 1.262 V。Adaptive 的 `Additional Turbo` 填 1.20 / 1.24，都低于这个值，主板没有把请求压下去，实际仍按 VID 供电。

ASUS Z97-AR 手册 2-29 列出的 CPU Core Voltage 模式是 `[Auto] [Manual Mode] [Offset Mode]`；实机 BIOS 另有核心 Adaptive，但这次的低目标值没有落地。手册 2-31 的 Adaptive / Additional Turbo 属于核显，不要和核心混在一起 `[手册]`。

结论：那轮"1.20 V 跑了 39 分钟"实际上是在 1.26 V 下跑的，不能当作 1.20 V 稳定。

### 5.2 内存 1.55 V 是下限

1.50 V 连开机都过不了，1.55 V 能过一小时内存测试，说明已经贴近边界。低电压方向没有余量，日常建议回加一档，或者至少复核冷启动、睡眠唤醒和真实应用。

### 5.3 温度与功耗

- 满载封装功耗约 97–101 W，最高温度 73–74 °C，室温 20–22 °C，离 Tjmax 还有约 27 °C。
- 空闲 13.9 W、31 °C，EIST 正常，800 MHz 与 4.7 GHz 之间切换正常。
- 对这套双塔风冷来说，100 W 级别压力不大，瓶颈不在散热。

## 6. 最终设置与建议

### 6.1 方案 A：手动（推荐）

| 项目 | 设置 |
|---|---|
| CPU Core Ratio | Sync All Cores → 47 |
| CPU Core Voltage | Manual Mode → Override 1.24 V 起步 |
| 稳定后日常 | Offset Mode → Sign **−** → 0.02 V 起（目标 1.20 V 约 −0.06 V） |
| LLC | Auto；掉压导致不稳再 Level 4 |
| CPU Cache Ratio | 40x 起步，核心稳定后试 44x |
| CPU Cache Voltage | Auto；不稳 +0.01–0.02 V |
| 内存 | XMP 2400，DRAM 1.55 V |

顺序：Manual 1.24 V 稳 47x → Cache 从 40x 往 44x 单独验证 → 改负 Offset，确认 Vcore 真的下降。1.24 V 是起步值，不稳就 +0.01 V。

### 6.2 方案 B：跟随 Tuner（只作对照）

1. Ai Tweaker → OC Tuner → **Ratio Only**（不要选 BCLK First，避免把 2400 内存带偏）。
2. 保存重启，记录 Tuner 给出的倍频与电压。
3. 复核内存是否仍是 2400 / 1.55 V；Tuner 可能改动内存参数。
4. Cache 通常仍是 40x/Auto，手动设到 44x 或保持 40x。
5. 跑稳定性；不稳回退手动。

Tuner 是"先跑起来"的起点，不是日常配置。这台机器的内存已经在下限，Tuner 改动内存参数的风险更高。

### 6.3 建议

- 日常先保持 47x + Adaptive 1.24 V + Cache 40x + DRAM 1.55 V。
- 想真正降压：按方案 A 先 Manual 验证，再转负 Offset；只看 Vcore，不看 VID。
- 内存如果追求长期余量，回加一档；1.55 V 只适合作为"已验证的下限"记录。
- 缓存等核心稳定后再单独提高，每次只改一项。

## 7. 踩坑清单

- 把 Adaptive 的 `Additional Turbo` 当成"目标电压"直接填低于 VID 的值，结果没有生效。
- 只看 VID 判断电压，没看 Vcore；这个平台上两者在默认状态几乎重合，容易误判。
- AIDA64 只勾了 `Stress CPU`，负载约 100 W，不能代表 FPU 或组合负载。
- 1.50 V 内存电压开机蓝屏，说明四条 DDR3-2400 对电压很敏感。
- HWiNFO 里 `PL1 / PL2 4.0959 W` 是显示缩放问题，不是真实限制。
