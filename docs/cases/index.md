案例按 **CPU + 主板** 归组：同一个平台的设置、测试和踩坑放在一起，先看这个平台的超频指导，再看同平台的具体案例。

## 怎么读

1. **先按 CPU + 主板找到平台。** 平台不同，能调的项目和顺序都不一样，别人的设置不能直接套用。
2. **读该平台的超频指导。** 里面写了先超什么、每步怎么测、什么算通过。
3. **再看同平台案例。** 案例给的是真实设置与实测读数，能对照自己的机器。

还没有案例时，以超频指导加原理篇为准：判断方法看[稳定性验证](/principles/08-stability)，工具操作看[烤机工具](/tools/)。

## 怎么投稿

一个案例只需要这几样，没有实测的部分写"未测试"，不要留空：

| 项目 | 要求 |
|---|---|
| 平台信息 | CPU、主板型号与 BIOS 版本、内存型号/容量/条数、散热、电源、室温 |
| BIOS 改动 | 只写改过的项；电压要写清模式（Auto / Manual / Offset）与数值 |
| 测试记录 | 用了什么工具、跑了多久、最高温度、有没有 WHEA 或报错 |
| 截图 | HWiNFO 满载读数、AIDA64 稳定性测试页、CPU-Z 内存与 SPD；BIOS 页面可以拍照 |
| 结论 | 最终日常设置，以及哪些改动真的生效、哪些没生效 |

案例不是晒分数，而是让别人能沿着你的设置复现，或者知道哪条路走不通。
