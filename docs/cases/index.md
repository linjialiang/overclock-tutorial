# 超友案例

这里收录真实的超频案例，一位超友一章。每章保留完整的平台信息、BIOS 设置、实测数据、踩坑和结论，方便你对照自己的机器。

| [案例 01：i7-4790K + Z97-AR](/cases/01-4790k-z97ar) | 47x + 32GB DDR3-2400 的日常设置 | 1.20/1.24 电压没有差别、内存 1.55 V 是下限 |

## 怎么写一篇案例

1. 先读[投稿模板与资源要求](/cases/template)，按清单准备材料。
2. 复制模板为 `docs/cases/NN-平台简称.md`，一人一章；同一人多次投稿合并更新。
3. 截图放到 `docs/public/cases/NN-平台简称/`，文件名用英文。
4. 数据必须真实：测了多久、最高温度多少、有没有 WHEA，都写清楚。
5. 官方规格和经验值分开标注，不要把社区说法写成官方结论。

案例不是"晒分数"，而是让别人能沿着你的设置复现结果，或者至少知道哪些路走不通。
