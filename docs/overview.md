# 超频概述

超频就是让 CPU、内存或核显跑在厂商默认频率之上。它不是一个开关，而是一组取舍：频率、电压、温度、稳定性四件事必须同时成立，缺一项就会以蓝屏、报错或降频的形式还回来。

这一章不展开细节，只把"超频在超什么、代价是什么、这份教程怎么读"讲清楚。

## 超频在超什么

| 对象 | 超的是什么 | 常见入口 |
|---|---|---|
| CPU | 倍频或外频，最终决定核心频率 | CPU Core Ratio、BCLK |
| 内存 | 频率与时序，常通过 XMP 一键套用 | XMP、DRAM Frequency、时序 |
| 核显 | iGPU 倍频 | GT Ratio / GPU Boost |
| 缓存（隐性） | Ring / Cache 倍频 | CPU Cache Ratio |

前三项是大多数人说的"超频"，第四项是容易被忽略的缓存频率。它不直接决定核心频率，但会影响核心访问 L3 和内存的延迟。

## 一次超频要同时满足什么

- **频率上去了**：目标频率能跑满，不因功耗墙或温度墙掉频。
- **电压够用**：该频率下不欠压，也不靠无意义的高压硬撑。
- **散热压得住**：满载温度在安全范围内，风扇噪音可接受。
- **负载下不出错**：没有 WHEA、没有计算错误、没有蓝屏，真实应用也能过。

只满足前三条、忽略第四条，就是"能开机但不算稳定"。只满足第四条、靠高温硬跑，则是用寿命换频率。

## 收益与代价

收益主要是多核性能、内存带宽和核显性能；代价是功耗、温度、噪音和稳定性风险。频率越高，边际收益越小：从 4.4 GHz 到 4.7 GHz 提升明显，从 4.7 GHz 到 4.8 GHz 往往要付出不成比例的电压和温度。

所以超频的目标不是"数字最大"，而是"在可接受的温度、噪音和稳定性下，找到适合日常的频率"。

## 五个常见误区

1. **"电压越高越稳"**——错。超过稳定所需之后，只会更热，不会更稳。
2. **"频率高就一定快"**——错。内存、缓存、散热跟不上时，频率提升会被抵消。
3. **"能开机就是稳定"**——错。开机只证明最低负载能过。
4. **"烤机通过就是永久稳定"**——错。只覆盖已测负载和当时的室温。
5. **"别人能跑我也能跑"**——错。体质、主板、散热、室温、内存都不同。

## 这份教程怎么读

1. **先读本章**，建立"三个对象 + 四道墙"的框架。
2. **再读[超频原理](/principles/)**，按需跳读：频率、电压、内存、缓存、核显、主板、电源散热、稳定性、调参。
3. **最后看[超友案例](/cases/)**，看别人在具体平台上怎么设、哪些设置真的生效、踩了什么坑。

原理篇不绑定具体平台；案例篇保留真实配置和数据，方便对照。

## 开始前的三条提醒

- **一次只改一项**，改完记录原始值和结果，否则出问题无法定位。
- **先记录默认状态**：频率、电压、温度、内存参数，后面才有对照。
- **稳定性以数据为准**：能开机、能跑分都不算稳定；要看满载时长、WHEA、真实应用和冷启动。
