# 超频概述

超频就是让 CPU、内存或核显跑在厂商默认频率之上。它不是一个开关，而是一组取舍：频率、电压、温度、稳定性四件事必须同时成立，缺一项就会以蓝屏、报错或降频的形式还回来。

这一章不展开细节，只把「超频在超什么、代价是什么、这份教程怎么读」讲清楚。

## 超频在超什么

![图 1：超频的四个对象——CPU 调倍频或外频，内存调频率与时序，核显调 iGPU 倍频，缓存 Ring 是隐性对象](/overview/01-targets.svg)

前三项是大多数人说的「超频」；缓存（Ring）不直接决定核心频率，但会影响核心访问 L3 和内存的延迟，所以单独列为第四项。

## 四道墙同时成立，才算超频成功

![图 2：频率、电压、散热、稳定性四道检查点全部通过，才到达稳定运行；任一项不成立都不算稳定](/overview/02-four-walls.svg)

- **频率上去了**：目标频率能跑满，不因功耗墙或温度墙掉频。
- **电压够用**：该频率下不欠压，也不靠无意义的高压硬撑。
- **散热压得住**：满载温度在安全范围内，风扇噪音可接受。
- **负载下不出错**：没有 WHEA、没有计算错误、没有蓝屏，真实应用也能过。

频率、电压、散热、稳定，就是后面反复提到的「四道墙」。只满足前三条、忽略第四条，是「能开机但不算稳定」；只满足第四条、靠高温硬跑，则是用寿命换频率。

## 收益递减，代价递增

![图 3：随频率提高，性能收益逐渐趋平，电压与温度代价越来越陡，中间是可接受的甜点区（示意图，非实测数据）](/overview/03-diminishing-returns.svg)

收益主要是多核性能、内存带宽和核显性能；代价是功耗、温度、噪音和稳定性风险。频率越高，边际收益越小 `[经验]`：从 4.4 GHz 到 4.7 GHz 提升明显，从 4.7 GHz 到 4.8 GHz 往往要付出不成比例的电压和温度。

所以超频的目标不是「数字最大」，而是「在可接受的温度、噪音和稳定性下，找到适合日常的频率」。

## 五个常见误区

![图 4：五个常见误区与对应事实——电压越高越稳、频率高就一定快、能开机就是稳定、烤机通过就永久稳定、别人能跑我也能跑](/overview/04-myths.svg)

## 怎么读这份教程

![图 5：阅读路径——先读本章建立框架，再按问题跳读原理篇九章，最后对照案例篇的真实配置与读数](/overview/05-reading-path.svg)

1. **先读本章**，建立「三个对象 + 四道墙」的框架。
2. **再读[超频原理](/principles/)**，按需跳读：频率、电压、内存、缓存、核显、主板、电源散热、稳定性、调参。
3. **最后看[超友案例](/cases/)**，看别人在具体平台上怎么设、哪些设置真的生效、踩了什么坑。

原理篇不绑定具体平台；案例篇保留真实配置和数据，方便对照。

## 动手前的三条提醒

![图 6：动手前记录默认值、一次只改一项、用 WHEA 与真实应用判断稳定性](/overview/06-before-start.svg)

- **先记录默认状态**：频率、电压、温度、内存参数，后面才有对照。
- **一次只改一项**：改完记录原始值和结果，否则出问题无法定位。
- **稳定性以数据为准**：能开机、能跑分都不算稳定；要看满载时长、WHEA、真实应用和冷启动。
