# 烤机工具

[稳定性验证](/principles/08-stability)讲的是"什么才算稳、为什么要分负载测"，这一篇讲"具体打开哪个软件、点哪里、看哪个数"。每个工具一页，用真实截图说明界面和读数，不重复原理。

五款工具分工不同，没有哪一款能单独给出"整机稳了"的结论：

| 工具 | 主要回答什么 | 什么时候用 | 形态 |
|---|---|---|---|
| [AIDA64](/tools/aida64) | 这台机器在持续负载下的温度、电压、功耗、频率曲线 | 需要一份完整的 CPU/内存压力测试记录 | Windows 软件，需安装 |
| [CPU-Z](/tools/cpuz) | 处理器、主板、内存的型号、频率、时序与 SPD 信息 | 核对 XMP 有没有生效、确认硬件身份 | Windows 软件，有便携版 |
| [HWiNFO](/tools/hwinfo) | 实时传感器读数与最小/最大/平均值 | 判断频率有没有掉、电压实际是多少 | Windows 软件，有便携版 |
| [TestMem5](/tools/testmem5) | 当前内存设置下会不会测出错误，错误计数是多少 | 超内存或改时序后做快速内存筛查 | Windows 软件，便携 |
| [MemTest86+](/tools/memtest86plus) | 不依赖操作系统，整机内存能不能通过长测 | 怀疑内存条本身有问题，或做长时间内存验证 | 独立启动，U 盘 |

## 推荐的验证顺序

1. **先确认身份**：[CPU-Z](/tools/cpuz) 看型号、频率、内存时序与 SPD，确认自己没有在测一台"设置没生效"的机器。
2. **再测内存**：[TestMem5](/tools/testmem5) 做短周期筛查；有报错或需要长时间验证时，用 [MemTest86+](/tools/memtest86plus) 从 U 盘启动复测。
3. **然后压 CPU**：[AIDA64](/tools/aida64) 勾选 CPU、FPU、cache 做组合负载，观察温度、功耗与频率是否稳定。
4. **全程盯读数**：[HWiNFO](/tools/hwinfo) 记录频率、Vcore、封装温度、封装功耗与 WHEA 计数。

顺序与[稳定性验证](/principles/08-stability)的"从窄到宽"一致：先单项、再组合，先内存、再 CPU。

## 三条使用原则

- **工具只负责它测的那一项。** 内存测试通过不代表 CPU 超频稳定，AIDA64 不报错也不代表冷启动没问题。
- **先记录再动手。** 每轮测试前记下 BIOS 设置、室温、软件版本与时长，否则结论无法复现。
- **截图与日志留证。** 只写"稳了"没有意义；把 Errors、耗时、最高温度截图存下来，出问题时才有对照。

每页截图都标注了软件版本与来源。软件更新后界面可能变化，按钮位置以你本机的实际界面为准。
